# Editable Bedrock guidebook assets

These are the existing port-authored handbook translations and 16×16 pixel book sprite from main ce8a45e. They are source inputs, not new upstream assets or AI imagery. `tools/convert_assets.py` copies the sprite and appends the translations when rebuilding, so model regeneration cannot erase the independent handbook. Update these files rather than generated RP language files. GPL-3.0-only, as the port.
