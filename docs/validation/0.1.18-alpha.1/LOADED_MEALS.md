# 原生料理計時（0.1.18-alpha.1）

2026-11-05，BDS 1.26.60.6、stable server 2.11.0／UI 2.0.0；原生冰箱原有 Upcoming Creator Features 保留。GameTest 及 beta 相依只用於隔離測試副本。

顧客改用原生實體 timer 與保存 property。七種動作維持原12／12／40／60／120／110／10 tick計數。餐盤獨立用原生方塊onTick，15／60／80／100 tick換食品階段；小型數字世界屬性保存食品進度，不逐tick重寫整間餐廳。收盤／拆機後移除其計數。

正常保存重開或離開模擬範圍不補算現實時間。原本只有毫秒時間的舊資料首次讀取時接續原進度。已領盤記錄保留至顧客原生反應完成，付款仍先保存一次性標記，再輸出原生物品；既有程序突然終止時世界資料與背包非原子寫入的限制仍在。

[37項原生結果](loaded-meals-native.json)包含交餐、食品與NPC一格一格推進、100 tick髒盤、120 tick加賞、早收取消、同世界保存重開、兩種時計在模擬範圍外暫停、舊時間資料轉換，以及上一個動作完成旗標不會讓新餐點提前付款。10 tick中斷至adapter移除，在實測中共13 tick；不宣稱零排程延遲。alpha.1僅depart_at的舊actor讀法另由來源回歸覆蓋。

重現主要交餐／重開場景的observer：[bedrock-loaded-meal-checks.js](../../../tests/bedrock-loaded-meal-checks.js)。只可匯入隔離QA入口；使用同一世界正常stop，停逾6秒後重開。其他邊界測試的結果如上。不在正式世界執行observer。

原生庫存／模擬玩家及正式adapter通過，不等於真人輸入、客戶端動畫或音效驗收。訂單期限仍按現實時間；食品限定／128堆疊、網路皮膚及其他[現存差異](../../PARITY.md)不因本修正而宣稱完成。OTC尚未首次安裝至LIVE。
