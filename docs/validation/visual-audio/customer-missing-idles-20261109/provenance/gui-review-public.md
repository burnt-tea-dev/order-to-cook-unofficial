# Four-scene GUI handoff

This preparation author has not used the GUI. All four files are frozen and
numerically checked, not visually accepted. Open them without saving changes.
No user-local computer, LIVE, Minecraft client or BDS is permitted for this task.

1. Verify scene-freeze-hashes.json before opening. Use an authorized cloud Blockbench setup only.
2. Capture one original full-window isometric photograph of each file in order:
   01_wide_wait2_head_query, 02_slim_wait2_head_query,
   03_wide_sit3_body_query, 04_slim_sit3_body_query. Keep both complete figures
   visible and unselected. Do not crop, align, resize or re-encode photographs.
3. Both sides are ordinary cubes in one common editor renderer. SOURCE is model
   X=-20, RP X=+20. Record actual screen-side mapping and preset; never assume
   source is screen-left. Each pair shares one untouched original skin.
4. For wait2, inspect the turned/pitched head above a forward-facing torso,
   hanging arms/sleeves, hands and straight legs. For sit3, inspect the whole-body
   turn/tilt, raised left arm/sleeve near head, torso-to-leg joins and both feet.
   Add North or side views only where an overlap obscures a useful surface.
5. Preserve default texture render mode and texture Auto sides. Record the
   already-current editor Render Sides state if visible; do not change it.
   Shared stippling or overlap must be retained as a diagnostic, not cleaned up.
6. Keep screenshots, capture receipts and later independent review separate from
   this preparation record. Bind each original photograph to scene SHA-256,
   camera, application provenance, complete/unselected status, synthetic query
   inputs and declared local clip time. Distinguish operator inspection from
   independent inspection. Record obscured areas and any renderer issue honestly.
7. Recheck scene hashes afterward. Do not save a scene to adjust framing or alter
   the frozen inputs. No numeric/static result is native acceptance or playback.

All four synthetic queries are target_x_rotation=15, target_y_rotation=-30.
Wait2 uses head-local [-15,30,0] at 0.375 s, with body rotation zero. Sit3 uses
body [-15,30,0] at 0.5833 s, with head-local zero and seated legs. These are not
observed native tracking inputs. Do not accidentally label sit3 head-only.
