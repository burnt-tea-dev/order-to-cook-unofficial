## 6. 物品、付款與重啟帳冊

進度的「本世界個人累積結算」記錄已保存的成功交單結算金額，包含小費及驚喜加賞；訂單存檔與實物發幣並非同一原子交易。將個人結算、餐廳統計與實際貨幣分開登帳，不把任何斷電時點的累積結算直接填成背包實收。正常流程以背包／地面貨幣增量核對付款；有差額時記操作時序、錯誤與重啟條件。
