## 後續有限批次（每列各自PASS/FAIL/BLOCKED；一次操作順便採聲畫與保存）

### 1. 外送＋HUD＋真成品容器身份（D-S07/N04–06/B05/D-H03/D-M04單人部分）
普通機器候選接一張外送，正常操作台打包；記食品/皮革/包裹proof對應訂單。先給普通 `/give @s ordertocook:takeout_bag 1` 作無身份負例，不可交付；有效包裹放車箱再取回，仍可完成一次。持有效票/包看設備→空地→轉身→步行→換物品，核世界東西南北/水平距離/XZ/剩餘分鐘及設備HUD共存；跨維度往返只在隔離世界以可用正常入口或明記tp診斷。沿HUD到真正目的地，錯包拒絕、正包只付款一次。另留一單自然到期，核失敗統計只加一次（等待不是永久blocker，可與家電批次並行）。一般/遠距/加急未抽到的分支PENDING_RANDOM，不改機率；診斷refresh可用但記次數，不據少量樣本驗機率。

### 2. 機車有限完整生命週期（B01–07）
`/give @s ordertocook:motorcycle 2`、`/give @s ordertocook:controller 1`；Survival空氣使用放1輛，核扣1；牆/已有車位置一次拒絕反例。上車前進後退/轉向/急停，平地/半磚/一格高差各一次，跳躍鳴笛、潛行離座。命名物及受損工具放54格貨箱，取回核metadata；與批次1有效包裹共用。持紅/藍/黃/白染料各改色一次，核各扣1；夜間面板/遙控各一次燈開關。含貨回收拒絕，清空下車後回收/再放同色。另車放可辨貨物，生存近戰每次間隔≥0.5秒，第1–5擊，核只回1車+貨物；不可因面板成功跳過5擊分支。純單人不驗旁觀者同步。

### 3. 工具箱成功/拒絕＋冰箱庫存（K01/K02/K07/I03）
`/give @s ordertocook:otc_upgrade_box 6`；正常放兩個上下空木桶、空煙燻爐、空池，用工具箱點下桶/爐/池，成功各扣1。各取有內容或上方被擋的樣本，拒絕不得吞內容/工具箱。冰箱用命名食品不同疊填上27/下54格（anvil命名或正常不同食品，避免自動合疊）；覆蓋>14條分頁、最後一格及超量/非食品拒絕，全部取回對帳。上下分區存不同可辨樣本，保存重入後取回。兩個新樣本分別拆上/下半，兩半互清且只返1設備+全部原貨。若填滿準備量大仍是可做，不標環境BLOCKED。

### 4. 洗碗機邊界及活動保存（K04/K06/K09）
`/give @s ordertocook:dirty_plate 33`。先8盤，再16盤各完整跑一次（覆蓋94tick/134tick兩時長分支），第17盤拒絕不扣。16盤活動中正常退出重入一次，記phase/remaining與盤數；完成後滿包領取應保留整批，騰位再只領一次。活動拆除返髒盤、完成待取拆除返乾淨盤各一樣本。不是66姿態每個都要再跑一次；未見phase仍列未觀察，不宣稱全部動作等價。

### 5. 爐灶三槽/燃料/堵塞（K05–07）
give原版minecraft:beef、minecraft:potato、minecraft:kelp、minecraft:coal、minecraft:lava_bucket；正常表單三槽各放一種與共用煤，約200tick後各出成品。一槽產物滿/全部滿/無效食材各一次，核受阻不扣料、全部受阻不新耗燃料。熔岩桶燃料留下空桶。燃燒中取走後備燃料，既有燃燒可用完；活動保存重入與之後拆爐返還對帳，不把離線變大量出菜當成功。

### 6. 成品/盤滿包與交易拒絕（I05/N08/N09）

### 7. 無椅/拆椅及真正卸載（N01/R03/R05）
