# Bedrock 客戶端實機驗收表

**文件狀態：待執行，2026-10-09。以下所有客戶端項目均未完成驗收。**

這是 `0.1.0-alpha.1` 的實機測試計畫，不是已通過的測試報告。專用服務端的載入、原生 API probe、持久化 probe 及自動測試結果另存於 `docs/validation/`；它們不能證明客戶端畫面、聲音、按鍵、觸控、騎乘手感或兩人操作已正常。本文件沒有預先勾選的通過項目。

## 1. 記錄方式與環境

每項結果只能填「未執行／通過／失敗／阻塞」，並附實際執行人、日期、環境代號和證據。沒有看到隨機事件、沒有對照版、缺少手機或未能連上第二位玩家時，記為「阻塞」，不能推定通過。修復後保留原失敗記錄，另填重測結果。

### Content Log 與證據

在客戶端「設定 → Creator／創作者」開啟 **Enable Content Log File** 和 **Enable Content Log GUI**。使用 **Content Log History** 匯出／複製訊息；可取得檔案時，使用該畫面顯示的實際路徑，不猜測不同版本的存放位置。鍵鼠可在開啟 GUI 後試用 `Ctrl+H`。方法以[官方 Content Error Log 文件](https://learn.microsoft.com/en-us/minecraft/creator/documents/contenterrorlog?view=minecraft-bedrock-stable)為準。

| 證據代碼 | 失敗時收集內容 |

## 3. 測試準備與載入

V／C 世界可使用診斷入口。以下在有權限的玩家聊天中執行；`otc_admin` 或創造模式是本包的管理員判定，不等於只拿到伺服器指令權限。

```mcfunction
/tag @s add otc_admin
/give @s ordertocook:guide
/scriptevent ordertocook:kit {}
```

也可從「下單了 · 基岩版指南 → 領取測試用開店套組」取得家具、18 個乾淨盤、3 個工具箱、車、遙控器、成品食品與皮革。套組不給測試金幣。測試區保持平地，家電上方留空，椅子上方留兩格空間；所有功能設備放在打單機 24 格內，兩架距操作台不超過 5 格。第二間測試餐廳的機器與第一間相隔超過 24 格。

僅在 C 世界需要縮短等待時，可在機器 24 格內使用：

```mcfunction
/scriptevent ordertocook:config {"refreshSeconds":10}
/scriptevent ordertocook:refresh {}
```

快速刷新會改變測試條件，需寫入記錄；S 世界維持 600 秒預設刷新。隨機訂單不保證下一輪就是堂食／外送／加急，記錄實際抽到的類型。不要用普通 `/give` 的餐點或外賣袋代替帶訂單身份的正式成品。

### 全部 41 個盤面 stage

原 `models/block/food_plate_anim/{型號}_{姿態}.json` 有 **10 型、每型 4 個姿態**。型號是原模型索引，不代表訂單必定含某種指定食品；本版裝盤隨機選型。一般打包只進入各型第一個姿態，不能靠完成幾張訂單就聲稱全部 stage 已測。

低位 `ordertocook:stage = stage % 16`，高位 `ordertocook:stage_high = floor(stage / 16)`。V 世界準備一個台面，對每個 stage 以四個朝向建立展示，拍照後換下一個 stage。命令展示只用於外觀，沒有有效訂單 proof。先確保下方有實心支撐；以下例子都寫到站立位置前方的同一格，觀察後再替換：

```mcfunction
/setblock ~2 ~-1 ~ minecraft:stone
/setblock ~2 ~ ~ ordertocook:food_plate_display ["minecraft:cardinal_direction"="north","ordertocook:stage"=0,"ordertocook:stage_high"=0]
/setblock ~2 ~ ~ ordertocook:food_plate_display ["minecraft:cardinal_direction"="north","ordertocook:stage"=0,"ordertocook:stage_high"=1]
/setblock ~2 ~ ~ ordertocook:food_plate_display ["minecraft:cardinal_direction"="north","ordertocook:stage"=0,"ordertocook:stage_high"=2]
/setblock ~2 ~ ~ ordertocook:food_plate_display ["minecraft:cardinal_direction"="north","ordertocook:stage"=8,"ordertocook:stage_high"=2]
```

以上依序是 stage **0、16、32、40**。替換 `north` 為另外三方向並按下表輸入所有值；對 `stage_high` 不使用布林值。`/setblock` 的 block-state 參數見[官方命令文件](https://learn.microsoft.com/en-us/minecraft/creator/commands/commands/setblock?view=minecraft-bedrock-stable)。這些是待客戶端執行的命令，不是本文件聲稱已跑過的紀錄。
