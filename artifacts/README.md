# 安裝包

目前版本：**0.1.1-alpha.2**。

- [整合 mcaddon](OrderToCook-Bedrock-0.1.1-alpha.2.mcaddon)：一般玩家下載此檔，以 Minecraft 匯入行為包與資源包。
- [獨立行為包](OrderToCook-BP-0.1.1-alpha.2.mcpack)／[獨立資源包](OrderToCook-RP-0.1.1-alpha.2.mcpack)：手動管理套件時使用，兩包必須配對。
- [SHA256SUMS.txt](SHA256SUMS.txt)／[build-info.json](build-info.json)：目前版本的下載雜湊與 runtime 指紋。

GitHub 檔案頁可用 **Download raw file** 取得原始檔；不要將網頁另存成 `.mcaddon`。先備份舊世界，再更新兩個包。安裝、玩法及已知差異見 [README](../README.md)；實際驗證範圍見 [VALIDATION](../docs/VALIDATION.md)。

## 舊版

[0.1.0-alpha.1 整合包](OrderToCook-Bedrock-0.1.0-alpha.1.mcaddon)、原 BP／RP 包及對應 [SHA-256](SHA256SUMS-0.1.0-alpha.1.txt)、[建置資訊](build-info-0.1.0-alpha.1.json) 保留供比對。回退到旧包不保證能讀取新版新增的餐盤狀態；需要回復時使用升級前的完整世界備份。
